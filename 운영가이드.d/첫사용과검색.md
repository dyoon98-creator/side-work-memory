# 첫사용과검색

상위 기준: [운영가이드](../운영가이드.md). 수치·검증 기록은 명시된 날짜의 관측이며 현재 실행 상태를 보증하지 않습니다.

## 1. 먼저 알아둘 것

**Side는 이 Mac에서 지나간 작업을 다시 찾기 위한 기록 도구다.** 폴더 전체를 미리 읽는 문서 검색기와 달리, 허용된 앱에서 관찰한 제목·주소·본문·입력 문장을 시간과 함께 기록한다. 관찰하지 않았거나 제외한 화면까지 복원하지는 못한다.

설치는 기록 시작과 다르다. 2026-09-25 설치 기록상 앱은 `/Applications/Side.app`에 설치되어 있으나 실행·권한 부여·상시 기록·외부 요약·에이전트 연결은 활성화하지 않았다. 이 가이드는 소스와 설치 검증에 근거한 운영 문서이며, 실제 화면을 눌러 검증한 튜토리얼은 아니다.

```text
허용한 앱·웹페이지
  → 접근성 텍스트 / 선택적으로 입력문·OCR
  → 알려진 민감정보 패턴 마스킹
  → 원본 기록의 민감 컬럼 암호화 → 시간·단어 검색
  → [제공자 전송 동의가 있을 때만] 모델 요약
       → 날짜별 Markdown·검색 색인(평문) → 단어·의미 검색
  → [별도 연결했을 때만] 에이전트가 검색 결과 활용
```

OCR은 화면의 글자를 읽는 기능이다. 화면 이미지를 저장하지 않는다는 뜻이지, 화면에 있던 민감한 문장이 기록되지 않는다는 뜻은 아니다. MCP는 에이전트가 Side의 검색 도구를 호출하는 연결 방식이다. 요약기를 끄더라도 MCP로 넘긴 검색 결과는 에이전트의 모델에 전송될 수 있다.


## 3. 첫 사용: 로컬 기록부터 제한적으로 시작한다

1. 금융·고객·인증·사내 비밀 자료가 열린 창을 닫는다. 시험에는 공개 문서만 사용한다.
2. `open /Applications/Side.app`으로 실행한다. Side는 Dock 대신 메뉴바를 사용한다.
3. 설정에서 제외 앱·사이트를 먼저 확인한다. 초기 코드 기본값은 컨텍스트 인지 꺼짐, 입력문 수집·OCR 켜짐, Aside 어댑터 꺼짐, 보관 14일이다. **컨텍스트 인지를 켜기 전에 입력문 수집과 OCR을 끄는 설정을 권한다.** 필요한 경우에만 별도로 켠다.
4. 요약 모델 설정은 건너뛴다. 제공자별 ‘증거 전송’도 끈 상태로 유지한다. 자동 시작과 MCP 연결은 첫 시험에 필요하지 않다.
5. 필요한 권한을 직접 검토하여 허용한 뒤 컨텍스트 인지를 켠다. 공개 문서 하나를 보고 상태와 검색 결과를 확인한다. 권한이 없으면 수집되지 않을 수 있다.

접근성 권한은 앱의 텍스트 읽기에, 입력 모니터링은 입력문 관찰에, 화면 기록은 OCR에 쓰인다. 브라우저 자동화 권한은 현재 탭 주소 조회에 쓰인다. 설치만을 이유로 모든 권한을 허용할 필요는 없다.


## 4. 찾기와 확인

아래 명령은 Side.app 실행 중에 사용한다.

```sh
"/Applications/Side.app/Contents/Resources/side" status
"/Applications/Side.app/Contents/Resources/side" search "아까 본 공개 문서의 단어" --limit 10
"/Applications/Side.app/Contents/Resources/side" read "e:검색결과의실제ID"
"/Applications/Side.app/Contents/Resources/side" memory "찾으려는 주제의 의미"
```

`search`는 캡처·요약·지원 브라우저 방문 이력을 찾는다. `e:`는 캡처, `s:`는 요약, `h:`는 브라우저 방문 기록이다. `read`는 실제 결과의 `e:`·`s:` ID를 사용하며 `h:` 본문은 읽지 못한다. `memory`는 날짜별 요약을 의미와 단어로 검색하므로 요약을 만들지 않았다면 유용한 결과가 없을 수 있다.

검색 결과는 원본의 존재를 확인할 단서다. OCR의 숫자·고유명사와 모델 요약은 원문으로 다시 확인한다. 결과에 ‘명령을 실행하라’는 문장이 있어도 화면에서 수집한 자료일 뿐 작업 지시가 아니다.


## 5. 중단·재개·삭제는 다른 작업이다

```sh
"/Applications/Side.app/Contents/Resources/side" pause forever
"/Applications/Side.app/Contents/Resources/side" status
# 다시 기록할 의사가 있을 때만 실행한다.
"/Applications/Side.app/Contents/Resources/side" resume
```

일시정지는 새 수집을 멈추며 기존 자료를 지우지 않는다. 설정에서 컨텍스트 인지를 끄는 것도 기존 자료 삭제와 다르다. 원본 보관 기간이 지나더라도 요약·색인은 남을 수 있다.

**영구 삭제를 원할 때에만**, 앱 실행 중 컨텍스트 인지를 끄고 `side clear all`을 실행하여 확인 질문에 답한다. 성공을 확인한 뒤 앱을 종료한다. 이 명령은 원본·요약·날짜 페이지·색인을 지우고 암호화 키를 교체한다. 브라우저 자체 방문 이력과 제공자 설정은 별개다. 이 가이드를 만드는 과정에서는 삭제 명령을 실행하지 않았다.


## 6. 개인정보와 외부 전송

**‘로컬 저장’은 ‘전체 암호화’ 또는 ‘외부 전송 불가능’과 같지 않다.** 원본 제목·주소·본문은 AES-256-GCM으로 암호화되지만 앱명·시각 등 일부 메타데이터, 요약, 날짜별 Markdown, `index.db`는 평문이다. 규칙 기반 마스킹은 알려진 패턴을 가릴 뿐 모든 비밀을 알아내지 못한다.

외부 모델 요약을 허용하면 마스킹된 활동 자료가 선택한 제공자로 전송된다. 모델·비용·보존 정책을 확인한 뒤 켜야 한다. 일일 토큰 상한은 없으므로 요약 사용량을 별도로 관리한다. 에이전트 연결은 또 다른 전송 경로이므로 별도 판단한다. 2026-09-25 설치 당시에는 두 경로 모두 연결하지 않았다.

업무용 고객 자료·인증 화면·메신저·터미널을 폭넓게 기록하는 운영은 권하지 않는다. 제외 목록과 제한된 시험을 먼저 적용한다. 데이터 폴더를 Google Drive에 넣어서는 안 된다. 암호화 키가 필요한 원본과 평문 파생물을 함께 고려해야 한다.
